# Base Materials

The builder uses base material files here, for example:

    RenderChunk.material.bin
    Sky.material.bin
    EndSky.material.bin

Base material files may be supplied separately from the builder source. They
remain Minecraft/RenderDragon data and are not covered by this repository's
MIT license. Include or redistribute them only when you have the legal right.
